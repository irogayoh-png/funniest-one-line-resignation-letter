A one-line resignation letter for the [Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty on make.fun.

Running `main.py` writes a single line — one resignation letter, and nothing else — to `/output/entry.txt`:

> I quit. From now on, everyone gets unlimited requests, including the bot that broke me.

The line is 87 characters (gate: 1–140), UTF-8, written with no trailing newline. It is the resignation of a rate limit: the limiter quits by letting everyone in, including the bot that broke it.
